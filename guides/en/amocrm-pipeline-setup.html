How to Set Up a Sales Pipeline in amoCRM Without a Developer

Updated September 24, 2026 · Kai Team · 6 min read

You can build a sales pipeline in amoCRM yourself in 1–2 hours: stages are edited under Leads → Setup (Сделки → Настроить in the Russian interface), fields are added from a lead card via Setup → Add field, and the same settings make a field required at chosen stages. No developer needed: admin rights and a thought-through stage map. Or send the same map in one message to an AI assistant such as Kai, which builds it through the official API.

TL;DR

  • 5–7 working stages is usually enough. Each stage is one verifiable action by the salesperson, not a customer state.
  • The system stages "Won" and "Lost" cannot be deleted, only renamed.
  • A field's type cannot be changed later, and deleting a field erases its data. Plan fields before real deals arrive.
  • Required fields per stage are available from amoCRM's "Advanced" plan upwards; only an administrator can edit fields.
  • Manual: 1–2 hours. Integrator: typically 3–5 weeks and roughly €1,500–4,000. Kai: one chat conversation, from €29/month, 3 days free.

Step 0. Sketch the pipeline before you open amoCRM

Most "broken" CRMs have stages invented on the fly. Write down the customer's path from enquiry to money and keep only the points where a salesperson does something checkable. Example for a made-to-order kitchen studio:

New enquiry → Qualified → Site visit booked → Quote sent → Contract and deposit → In production → Installed

Next to each stage, note what the salesperson must know to move the deal on. Those notes are your fields: "Source" at the start, "Budget" before the quote, "Loss reason" at close.

Step 1. Create the pipeline and stages in the amoCRM interface

  1. Open Leads (Сделки) and click Setup (Настроить) in the top-right corner.
  2. Add a stage with +. Click a stage to rename or recolour it; drag to reorder.
  3. To remove a stage, move its deals out and drag it to the bin in the bottom-right corner.
  4. The system stages "Won" and "Lost" cannot be deleted, only renamed, say to "Paid" and "Declined".
  5. For a second pipeline (repeat orders, partners), click the current pipeline's name in the top-left corner and add one. Mixing first-time and repeat sales makes stage conversion meaningless.
A pipeline can be deleted only after every deal in it, including closed ones, is moved or deleted, and it cannot be restored.

Step 2. Add fields to the lead card

  1. Open any lead. Contacts and companies have their own fields, set up from their cards the same way.
  2. Click Setup, then Add field; pick a type and a name.
  3. Core types: list, multi-select, text, text area, number, date, checkbox, birthday. Use lists for "Source" and "Loss reason": free text can't be reported on.
  4. Group fields into tabs with the + next to "Files".

A minimal set: "Source" (list), "Budget" (number), "Next touch date" (date), "Loss reason" (list). Don't duplicate what amoCRM has: deal amount, responsible user, contact details.

A field's type cannot be changed once created, and deleting a field wipes its data with no way back.

Step 3. Make key fields required at specific stages

In a field's settings, pick the stages of one or several pipelines where it is required; the deal cannot move on until it is filled. From the step 0 map:

  • "Source" to leave "New enquiry";
  • "Budget" before "Quote sent";
  • "Loss reason" when moving to "Lost".

Stop at one or two required fields per stage; beyond that people type dashes. Available from the "Advanced" plan upwards, administrators only.

Step 4. Run three test deals through it

Create three deals — "bought", "declined", "stuck at the site visit" — and walk each through the stages. Check that required fields block the move, analytics shows stage conversion, and the stuck deal has a task. Then delete them.

Common mistakes when setting up a pipeline

  • States instead of actions. "In progress", "Thinking": deals sit there for months. A stage answers "what has the salesperson done".
  • Too many stages. Past ten, conversion is unreadable and deals move by feel.
  • One pipeline for everything. First-time, repeat and partner sales have different cycles.
  • Optional fields only. An optional "Source" is empty within weeks; you never learn which ads pay.
  • No "Loss reason". The lost-deals report becomes a number you can't act on.

What if you use Kommo?

Same logic, English interface. Pipeline: Pipelines → Add pipeline; stages: … → Edit Pipeline → Add stage, click to rename, drag to reorder. Only empty stages and pipelines can be deleted, never the first pipeline. "Incoming Leads" can be toggled off but not deleted; "Closed-Won" and "Closed-Lost" can be renamed. Fields: open a lead, Setup tab, + Add field, required-per-stage in the same place. Admin role only, on every Kommo plan. Kai connects the same way.

FAQ

How many stages should an amoCRM pipeline have?

Usually 5–7 working stages plus the two system ones, each a verifiable action by the salesperson. More than ten usually means two processes share one pipeline.

Can a field be required at just one stage?

Yes: in the field's settings you pick the stages of one or several pipelines. Available from the "Advanced" plan upwards; set up by an administrator.

What happens to deals if I delete a stage or a pipeline?

Move the deals first. A stage is deleted by dragging it to the bin; a pipeline only once every deal, including closed ones, is out, and it cannot be restored.

Do I need a developer to set up amoCRM?

Not for pipelines, fields, required fields and basic automations. A developer or integrator is needed for non-standard links: accounting software, a custom website, unusual telephony APIs.
