Assistant IA pour Pipedrive : configurer votre CRM par message de chat

Mis à jour le 3 novembre 2026 · Équipe Kai · 5 min de lecture

Un assistant IA pour Pipedrive, c’est un chat dans lequel vous décrivez votre processus de vente avec vos propres mots, et qui le construit dans Pipedrive via l’API officielle : pipelines et étapes, champs, transactions, personnes, organisations, activités et notes. Kai le fait dans Telegram ou dans le navigateur. La prise en charge de Pipedrive est en bêta : la structure, les données, les activités et l’analytique fonctionnent ; les automatisations sur les événements Pipedrive arrivent ensuite.

En bref

  • Installation via le lien app.aii-crm.com/install/pipedrive : Pipedrive demande l’autorisation, puis Kai associe cette entreprise Pipedrive à votre compte dans Telegram ou le chat web.
  • Ce qui fonctionne : pipelines et étapes, champs de transaction, de personne et d’organisation avec listes d’options, transactions, personnes, organisations, activités, notes, utilisateurs, analytique du pipeline avec transactions gagnées et perdues.
  • Pas encore : les règles sur les événements Pipedrive (automatisations et intégrations de Kai) et les boutons ou panneaux dans Pipedrive.
  • Disponible à partir du forfait Start, €29 par mois. Les 3 premiers jours sont une période d’essai.

Comment connecter Pipedrive à Kai

  1. Ouvrez le lien d’installation et connectez-vous à Pipedrive si on vous le demande.
  2. Pipedrive indique à quelles données Kai demande l’accès. Autorisez l’accès.
  3. Sur la page « Kai is installed in Pipedrive », cliquez sur « Open Kai in Telegram » ou « Continue in the browser ». Le lien ne fonctionne qu’une fois, pendant 30 minutes : il associe cette entreprise Pipedrive à votre compte Kai.
  4. Kai confirme la connexion et demande ce qu’il faut configurer.

Deux autres possibilités, directement dans le bot @aiicrm_bot ou le chat web : la commande /connect → « Pipedrive (beta) » → « Sign in with Pipedrive », ou l’envoi d’un token API personnel : Pipedrive → avatar → Préférences personnelles (Personal preferences) → onglet API.

La connexion via Pipedrive utilise OAuth : Kai ne voit jamais votre mot de passe Pipedrive. Un token API agit en votre nom, ne le publiez donc pas. Régénérez-le dans les mêmes paramètres et l’ancien cesse de fonctionner.

Ce que Kai configure dans Pipedrive

  • Pipelines et étapes. Un nouveau pipeline avec ses étapes en un seul message ; ajouter, renommer ou supprimer une étape.
  • Champs. Des champs personnalisés sur les transactions, les personnes et les organisations, y compris des listes d’options, et leurs valeurs sur une transaction.
  • Transactions. Créer, déplacer d’une étape à l’autre, modifier le montant et le responsable, rechercher ; un lien vers la fiche de la transaction dans Pipedrive.
  • Personnes et organisations. Les créer et les lier à une transaction.
  • Activités et notes. Une activité avec échéance sur une transaction et une note, directement depuis le chat.
  • Analytique du pipeline. Transactions par étape, transactions gagnées et perdues, la « santé » d’une transaction donnée.

Chaque action passe par l’API officielle de Pipedrive. Tout ce qui est créé reste dans votre entreprise Pipedrive, que vous continuiez ou non à utiliser l’assistant.

Avec Kai, un seul message suffit

Vous décrivez votre activité, Kai pose des questions de précision, montre un plan, crée tout via l’API après votre confirmation et envoie un rapport. Exemples :

Crée dans Pipedrive un pipeline pour la vente B2B : Nouveau lead → Qualifié → Démo → Proposition → Négociation → Contrat. Ajoute aux transactions un champ numérique Budget et un champ liste Source avec Site web, Recommandation, Événement.

Les forfaits sont les mêmes que pour les autres CRM : Start à €29 par mois pour un CRM, Pro à €59 jusqu’à trois CRM, Max à €119 jusqu’à dix. Les 3 premiers jours sont une période d’essai, sans carte, avec environ 25 requêtes sur les fonctions Start. Kai parle anglais et russe.

FAQ

Existe-t-il un assistant IA qui configure Pipedrive à partir d’un message de chat ?

Oui, Kai. Vous décrivez votre processus de vente avec vos propres mots dans Telegram ou le navigateur, et Kai crée dans Pipedrive, via l’API officielle, pipelines et étapes, champs, transactions, personnes, organisations, activités et notes, puis analyse le pipeline. La prise en charge de Pipedrive est en bêta.

Comment connecter Pipedrive à Kai ?

Ouvrez le lien d’installation app.aii-crm.com/install/pipedrive, autorisez l’accès dans Pipedrive et, sur la page « Kai is installed », cliquez sur « Open Kai in Telegram » ou « Continue in the browser ». Deux autres possibilités dans le bot : /connect → Pipedrive (beta) → « Sign in with Pipedrive », ou un token API personnel issu de vos paramètres Pipedrive.

Kai peut-il créer des automatisations dans Pipedrive ?

Pas encore. Les règles sur les événements Pipedrive (une transaction passe à une étape → une tâche ou une notification) et les intégrations événementielles arriveront après la bêta. Aujourd’hui, Kai configure la structure, gère les données et les activités et analyse le pipeline.

Quel forfait faut-il pour Pipedrive ?

N’importe quel forfait à partir de Start, €29 par mois pour un CRM. Les 3 premiers jours sont une période d’essai sans carte, de quoi tester Kai sur votre propre entreprise Pipedrive.

Et ensuite ?

Ouvrez le lien d’installation, autorisez l’accès et demandez à Kai d’afficher vos pipelines : en une minute, vous voyez l’assistant travailler avec votre entreprise.
