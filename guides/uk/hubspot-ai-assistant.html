ШІ-асистент для HubSpot: налаштування CRM за повідомленням у чаті

Оновлено 4 листопада 2026 · Команда Kai · 5 хв читання

ШІ-асистент для HubSpot — це чат, у якому ти звичайними словами описуєш свій процес продажів, а він працює з HubSpot через офіційний API: показує воронки й угоди, створює угоди, контакти, задачі й нотатки та розбирає воронку. Kai робить це в Telegram або в браузері. Уже сьогодні HubSpot підключається через API як власна CRM; підключення в один клік — у розробці.

Коротко

  • Зараз: ключ service key з HubSpot плюс готова специфікація Kai — підключення власної CRM через API на тарифі Max.
  • Працює: воронки й етапи, угоди (список, пошук, створення, зміна етапу й суми), контакти, задачі й нотатки по угоді, аналітика воронки.
  • У розробці: застосунок Kai для HubSpot з кнопкою «Увійти через HubSpot» і посиланням для встановлення — без ключів і JSON.
  • Поки немає: створення воронок і полів, компаній, автоматизацій за подіями HubSpot.

Як підключити HubSpot до Kai вже сьогодні

  1. У HubSpot відкрий Development → Keys → Service keys і натисни Create service key. Створити ключ може суперадмін або користувач із правом Developer tools.
  2. Назви ключ «Kai» і додай права доступу (scopes): crm.objects.deals.read, crm.objects.deals.write, crm.schemas.deals.read, crm.objects.contacts.read, crm.objects.contacts.write. Натисни Create і скопіюй ключ.
  3. Відкрий сторінку підключення власної CRM, розділ «Ready-made specs: HubSpot», скопіюй JSON і встав ключ у поле token.
  4. У боті @aiicrm_bot або у веб-чаті: /connect → «My own CRM via API» → встав JSON. Kai перевірить доступ і покаже твої воронки угод.
Ключ service key діє від імені акаунта HubSpot — не публікуй його. У HubSpot його можна перевипустити або видалити — тоді старий ключ перестане працювати.

Що Kai робить у HubSpot

  • Воронки та етапи. Показує воронки угод та етапи, рахує угоди на кожному етапі.
  • Угоди. Знаходить угоду за назвою, створює нову в потрібній воронці й на потрібному етапі, змінює етап і суму.
  • Контакти. Створює контакт із телефоном і електронною поштою.
  • Задачі та нотатки. Ставить задачу з терміном і додає нотатку до угоди.
  • Аналітика. Скільки угод на кожному етапі воронки.

Кожна дія йде через офіційний API HubSpot. Усе створене залишається у твоєму акаунті HubSpot незалежно від того, чи користуватимешся ти асистентом далі.

FAQ

Чи є ШІ-асистент, який працює з HubSpot за повідомленням у чаті?

Так, Kai. Уже сьогодні він підключається до HubSpot через API як власна CRM: бачить воронки й угоди, створює угоди, контакти, задачі й нотатки, пересуває угоди між етапами та розбирає воронку. Підключення в один клік — у розробці.

Як підключити HubSpot до Kai вже сьогодні?

Створи в HubSpot ключ: Development → Keys → Service keys, з доступом до угод і контактів. Візьми готову специфікацію HubSpot на сторінці підключення власної CRM, встав у неї ключ і надішли Kai: /connect → «My own CRM via API». Підключення власної CRM доступне на тарифі Max.

Коли з’явиться підключення HubSpot в один клік?

Воно в розробці: застосунок Kai для HubSpot із кнопкою «Увійти через HubSpot» і посиланням для встановлення, без ключів і JSON. Щойно запустимо, Kai напише про це в чаті.

Чого Kai поки не робить у HubSpot?

Не створює воронки й поля, не працює з компаніями і не запускає автоматизації за подіями HubSpot. Усе це заплановано разом із підключенням в один клік.
